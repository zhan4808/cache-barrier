## 5. The story so far, in one paragraph (for re-grounding)
We set out to answer when quantization actually speeds up inference. The answer
is a bounded window with measured edges: quant loses when its operand is
L2-resident (and that regime dies under serving contention — step function),
wins ~byte-ratio when HBM-streamed, super-proportionally at the boundary where
quantization pulls the operand into L2 (microbenchmark-only), and weight-only
quant dies at the compute edge (dequant ceiling) while matched-precision W8A8
never cliffs (1.8–1.9× vs tuned bf16 everywhere). KV is outside the capacity
story entirely. On top of the physics, five kernel-implementation mechanisms
(tile starvation, wave bands, dispatch splits, occupancy floors, BLOCK_M
staircases) each independently flip win↔lose — so the deliverable direction is
CARM + per-kernel predicates = a routing layer, validated by (in-flight) served
A/B + real-model accuracy, with native-FP4 on Blackwell as the one untested
prediction.
